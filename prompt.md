*📌 Tugas Mata Kuliah Cryptography:*

Membuat aplikasi steganografi yang dapat menyisipkan dan membaca pesan tersembunyi pada berbagai media, seperti gambar, video, audio, dan lainnya.

//CMIIW

- tolong buatkan aplikasinya menggunakan bahasa pemrograman rust
- aplikasi desktop offline berbasis gui
- wajib menggunakan komentar dan komentarnya wajib pakai bahasa indonesia
- outputnya wajib pakai bahasa indonesia
- kodenya wajib pakai bahasa indonesia seperti nama class dan nama function dan nama variable dan masih banyak lagi
- suatu file jangan menyentuh 1000 baris kode , maksimal 950 baris kode
- aplikasinya jangan hanya 1 file saja , wajib dipecah pecah jadi banyak file dan banyak folder
- keamanannya sangat tinggi baik itu keamanan dari internal seperti pakai error handling dan keamanan dari eksternal (keamanan dari serangan hacker) seperti file binarynya tidak mempan reverse engineering
- kecepatan performanya sangat cepat
- sizenya sangat kecil (file binarynya)
- penggunaan size resource usagenya sangat ringan (bahkan bisa run di laptop kentang karena saking ringannya)
- nama filenya wajib bahasa indonesia
- nama foldernya wajib bahasa indonesia
- jangan sampai ada kondisi kode long line (1 baris kode yang sangat panjang sampai ke kanan, jadi di IDEnya harus digeser)
- tolong ikuti kebiasaan/best practice para senior rust developer seperti clean code yaitu contohnya setiap nama variabel ada maknanya/ada maksudnya dan masih banyak lagi (dan karena clean code jadi seharusnya kodenya sangat mudah dimaintenace dan sangat mudah dibaca dan dipahami developer/engineer), selanjutnya yaitu misalnya untuk hasilkan sesuatu bisa dengan 2 opsi opsi pertama itu pakai 1 baris kode opsi kedua itu pakai 50 baris kode misalnya dan keduanya hasil outputnya sama saja nahh best practicenya itu selalu pakai opsi yang kodenya lebih sedikit (usahakan kodenya jangan bertele tele kalau bisa ya, kalau tidak bisa ya mau gimana lagi), selanjutnya yaitu menghilangkan kebiasaan membuat scratch dari nol jadi misalnya mau buat sesuatu dan udah ada librarynya ya tinggal pakai library yang sudah dipercaya aja gitu usahakan cari dulu librarynya kalau emang ga ada baru scratch dari nol (harusnya bahasa rust itu melimpah library)
- oh ya saya pakai osnya itu bazzite (dan ini turunan fedora tapi immutable jadi ga boleh pakai dnf, karena itu untuk tool clinya pakainya homebrew)
- sudah pasti pakai konsep kriptografinya

- boleh pakai konsep sinkronus kalau emang diperluka ya

- terapkan Functional Testing (UAT,Exploratory testing,Sanity Testing,Regression Testing,Smoke Testing,Unit Testing,Integration Testing,Mocking) dan Non-Functional Testing (Load Testing,Performance Testing,Stress Testing,Security Testing,Accessibility Testing) di dalam kodenya atau script
- wajib pakai git, wajib pakai dokumentasi README.md (ini isinya bahasa indonesia dan jangan ada emoticon), wajib pakai .gitignore (isinya wajib yang emang jangan dimasukkan ke dalam repo githubnya), dan branchnya wajib main ya jangan master (ini harusnya udah default main sih)
